# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Implemented the BitMiner cryptocurrency miner and converter application. Kaelen Thorne designed the linear-gradient UI layout and tab navigation ('Mine' and 'Convert'). Lyra Van Dyk implemented the base64 email generation, key generation, combined BLAB payload generator, auto-convert logic, live feed terminal log output using core variables blab, miner_identity_email, and app_user_selected_amount, along with PWA support. Mint Reyes verified code correctness, build compatibility with Vite, and cross-device responsive design.

## Files changed

- `index.html` — Updated HTML structure with meta tags, PWA manifest linkage, and link to CSS stylesheet.
- `style.css` — Created unified linear-gradient styling, theme variables, and terminal styling.
- `main.js` — Implemented full mining and conversion logic using core variables blab, miner_identity_email, app_user_selected_amount, feed terminal logger, tab navigation and PWA support.
- `manifest.json` — Created web app manifest for PWA app downloading functionality.
- `sw.js` — Created service worker script for PWA offline caching and installation support.
