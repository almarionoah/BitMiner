# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Kaelen Thorne, Lyra Van Dyk, and Mint Reyes collaborated to build the BitMiner frontend application using Vite. The application features a cryptocurrency miner interface with linear-gradient styling, two menu options ('Mine' and 'Convert'), base64 encryption for generated email identities and keys, and automatic output responses to the feed terminal incorporating the required core variables [blab], [miner_identity_email], and [app_user_selected_amount]. PWA capabilities and responsive design tokens were fully integrated.

## Files changed

- `index.html` — Updated index.html to include professional typography, proper title, and viewport meta tags for responsive PWA and desktop styling.
- `package.json` — Added vite-plugin-pwa dependency to support PWA app downloading functionality.
- `vite.config.js` — Configured Vite with PWA plugin support as requested by engineering requirements.
- `src/style.css` — Created design system stylesheet with linear gradients, modern CSS variables, card layouts, and terminal styling.
- `main.js` — Implemented core application logic adhering strictly to project requirements: Mine and Convert menu options, base64 email & key generation, user selected amount [app_user_selected_amount], mined [blab] tokens, conversion algorithm, feed terminal outputs, and PWA integration.
