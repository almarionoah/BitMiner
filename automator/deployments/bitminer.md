# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Kaelen Thorne planned the application architecture and PWA layout; Lyra Van Dyk engineered the cryptocurrency miner and conversion engine adhering to the exact specification with core variables [blab], [miner_identity_email], and [app_user_selected_amount], live terminal feed, and linear-gradient visual design; Mint Reyes reviewed and verified syntax, PWA service worker registration, and Vite build compatibility.

## Files changed

- `index.html` — Update index.html with complete semantic markup, linear gradient branding, Mine/Convert navigation, conversion parameters with [miner_identity_email] and [app_user_selected_amount], real-time metrics, PWA install prompt button, and the feed terminal.
- `src/styles.css` — Create styles.css with high quality linear-gradient color schemes, cyber-dark theme, glowing crypto badges, responsive grid layout, and terminal styling.
- `src/miner.js` — Implement BitMinerEngine class with mining cycles that generate Base64 encoded email + Base64 key to produce [blab], and conversion processing strictly applying [blab], [miner_identity_email], and [app_user_selected_amount] with automatic feed output logging.
- `main.js` — Wire main.js to control Mine and Convert views, form input fields, auto-convert, live feed terminal updates, JSON export, and PWA installation.
- `public/manifest.json` — Add PWA web manifest file supporting application downloading with standalone mode, icons, and theme colors as requested in work assets.
- `public/sw.js` — Add service worker in public directory for PWA offline caching and installation support.
