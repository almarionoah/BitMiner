# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Kaelen Thorne planned the cryptocurrency miner application structure with 'Mine' and 'Convert' menu views. Lyra Van Dyk implemented the core functionality including base64 email auto-generation, base64 key value generation, interactive feed terminal, pwa capability, and proper processing algorithm using [blab], [miner_identity_email], and [app_user_selected_amount]. Mint Reyes reviewed and verified the code quality, ensuring linear-gradient styling, responsiveness, and robust conversion processing.

## Files changed

- `index.html` — Update HTML head with title, meta tags, PWA manifest link, and body classes for the crypto miner app.
- `manifest.json` — Add Web App Manifest for PWA functionality and installability.
- `package.json` — Add lucide-react dependency for UI icons.
- `main.js` — Initialize React root and mount the main App component with stylesheet.
- `src/styles.css` — Define global theme, linear-gradient variables, and custom styling rules.
- `src/App.js` — Implement full React frontend with Mine and Convert tabs, base64 email & key generators, interactive terminal, and conversion processing logic using [blab], [miner_identity_email], and [app_user_selected_amount].
