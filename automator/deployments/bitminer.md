# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Kaelen Thorne planned and structured the Vite-based BitMiner cryptocurrency mining application with linear-gradient aesthetics and PWA support. Lyra Van Dyk implemented the core 'Mine' and 'Convert' menu views, auto-generated base64 email and key generation algorithms using the required variables ([blab], [miner_identity_email], [app_user_selected_amount]), live feed terminal output, and custom amount inputs. Mint Reyes reviewed and verified all code against the requirements, ensuring correct data conversion processing, responsive styling, and a clean build output.

## Files changed

- `package.json` — Ensure package.json remains intact with all necessary dependencies and build scripts.
- `index.html` — Update index.html with appropriate title, Google Fonts, and root container for the SPA.
- `main.js` — Initialize the application entry point and global styles.
- `src/style.css` — Provide linear-gradient design system and component styles.
- `src/app.js` — Implement core frontend logic for mining simulation, base64 encryption, terminal logging, and conversion processing using [blab], [miner_identity_email], and [app_user_selected_amount].
