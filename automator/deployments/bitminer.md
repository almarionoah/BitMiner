# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Implemented BitMiner cryptocurrency mining and conversion application according to engineering specs. Lead Lead Release Engineer coordinated team contributions: Kaelen Thorne structured the modular app and tabs layout; Lyra Van Dyk authored the linear-gradient design system, Base64 blab mining loop, conversion algorithm incorporating core variables [blab], [miner_identity_email], and [app_user_selected_amount], auto-conversion pipeline, terminal feed logs, and PWA download capabilities; Mint Reyes reviewed edge cases, input handling, and build compliance.

## Files changed

- `index.html` — Updated index.html to include metadata, PWA manifest link, stylesheet import, and root app container.
- `public/manifest.json` — Added PWA web app manifest for application installation and downloading.
- `style.css` — Created design system with linear-gradient aesthetics, dark theme cyber styling, responsive layout, and custom terminal formatting.
- `main.js` — Implemented full mining and conversion application logic using [blab], [miner_identity_email], and [app_user_selected_amount], auto-convert terminal feed outputs, and PWA integration.
- `sw.js` — Created lightweight service worker file to support PWA downloading and offline caching capabilities.
