# Automator deployment — BitMiner

Project type: **vite**  
Build: `.: npx vite build --mode development`  
Developers: Kaelen Thorne, Lyra Van Dyk, Mint Reyes  
Base branch: `main`

## Summary

Kaelen Thorne planned the structure for the BitMiner crypto miner application with 'Mine' and 'Convert' tabs using a linear-gradient styling, Lyra Van Dyk implemented the complete frontend logic including base64 email generation, key generation, feed terminal output, and dynamic amount conversion utilizing the core variables [blab], [miner_identity_email], and [app_user_selected_amount], and Mint Reyes reviewed and verified the code against the project specifications and build constraints.

## Files changed

- `index.html` — Updated index.html with appropriate title, meta tags, manifest link, and body class for the BitMiner app.
- `package.json` — Ensured package.json has correct scripts and version for Vite build.
- `vite.config.js` — Configured Vite with outDir and target.
- `manifest.json` — Added PWA manifest.json to satisfy PWA download and functionality requirements.
- `main.js` — Implemented complete BitMiner cryptocurrency miner and conversion logic with base64 generation, terminal output, and core variable processing.
- `style.css` — Provided stylesheet with base styling and Tailwind directives.
